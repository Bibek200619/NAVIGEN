# Canonical v1 enums

- `robot_status`: `idle`, `navigating`, `manual`, `offline`, `error`
- `connection_status`: `connected`, `disconnected`, `connecting`
- `mission_status`: `pending`, `in_progress`, `completed`, `failed`, `aborted`
- `command_status`: `pending`, `accepted`, `rejected`, `executed`, `failed`
- `safety_state`: `ok`, `warning`, `emergency_stop`
- `localization_state`: `initializing`, `tracking`, `lost`, `relocalizing`
